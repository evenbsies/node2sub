节点转订阅地址

贴入节点，立马生成一条自适应订阅地址：不用选软件，转换服务按客户端身份实时返回对应格式（Clash / sing-box / Surge / Quantumult X / Loon / 通用链接）。节点文件仍写进你自己的 GitHub 仓库，不经过任何第三方服务器。

说明：发布 = 调 GitHub Contents API 写文件（已存在则覆盖，需先读 SHA），节点文件仍在你自己仓库里。
自适应原理：单个静态文件没法按客户端变格式，所以多了一个转换服务（server/ 目录，无状态，不存节点）：客户端拿着这条链接来拉时，服务按 User-Agent 识别身份——Clash/Mihomo/Stash 给 Clash YAML，sing-box 给 sing-box JSON，Surge / Quantumult X / Loon 各给自家配置，其他一律给 Base64 订阅；链接后加 &target= 也可强制指定格式。
链接本身拿到就能拉，这是订阅链接固有的；和公开粘贴服务的区别是文件在你自己仓库里，转换服务也由你自己部署。
