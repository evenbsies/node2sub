节点转订阅地址

贴入节点，选个格式，生成可直接订阅的链接。内容写进你自己的 GitHub 仓库，走 jsDelivr 分发，不经过任何第三方服务器。

说明：发布 = 调 GitHub Contents API 写文件（已存在则覆盖，需先读 SHA），返回的订阅链接是 https://cdn.jsdelivr.net/gh/仓库@分支/路径。
链接本身拿到就能拉，这是订阅链接固有的；和公开粘贴服务的区别是文件在你自己仓库里。
结构化格式（Clash / sing-box / Surge / Quantumult X / Loon）需要完整节点链接，纯 IP:端口行无协议信息会被跳过并计数提示；想转纯 IP 行，先用 CFProbe 的节点模式导出完整链接再贴过来。
Surge / Quantumult X / Loon 不支持 vless / hysteria2 / tuic（按各软件文档协议范围映射），这类节点会被跳过并提示，不会静默丢失。
jsDelivr 有缓存，刚发布后几分钟内可能还是旧内容。
